# 第二種電気工事士 技能試験 複線図ドリル（PDF）— 仕様メモ v0

## 狙い
- 買う人: 技能試験の受験者（独学・社会人）。感情の核は「本番で複線図が書けずに手が止まる不安」。
- 価格仮説: ¥980（BOOTH）。無料版は「手順の型＋例題1問」で note 記事から誘導。
- 時期: 下期技能試験の前（例年 年末ごろ。日程は試験センターの公表で要確認）に出品できるよう、10月中に完成させる。

## 中身（案）
1. 複線図の「型」7ステップ（接地側→電源→スイッチ→渡り線→電線色→接続点→リングスリーブ/差込コネクタ）
2. 部品別の書き方（片切スイッチ、3路/4路、パイロットランプ常時点灯・同時点滅・異時点滅、コンセント、タイマ等）
3. 例題ドリル 10問前後: 単線図 → 解答の複線図 → 電線色・スリーブ刻印のチェック表
4. 本番でよくあるミス一覧（接地側の色、渡り線の本数、スリーブ刻印の小/中）

## 守ること（品質ルール）
- 試験センター公表の候補問題の図面は **転載しない**。回路はすべて自作（候補問題の要素＝部品の組み合わせを練習できる構成にする）。
- スリーブの刻印・サイズ組合せなど、自信のない数値は入れず backlog に「要確認」で残す。
- 表紙と最終ページに免責（試験の正式な判定基準は試験センターの公表資料が優先）を入れる。

## 作り方（技術）
- `build.py` で reportlab（pip で導入可・確認済み 2026-09-28）＋ IPAゴシック（`/usr/share/fonts/opentype/ipafont-gothic/ipag.ttf`）で PDF を生成。
- 回路は「部品と接続のデータ（dict）」で定義し、複線図は同じデータから描画する → `test_build.py` で「全接続点に接地側/非接地側の矛盾がない」「各スイッチの渡り線本数」などを機械的に検証する。
- 最初の一歩: 片切スイッチ1灯＋コンセントの1問だけで、描画と検証のパイプラインを通す。
