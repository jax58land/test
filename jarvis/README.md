# えふぃぞー（「ヘイ、ジャービス！」の自分版）

添付PDF「ヘイ、ジャービス！」完全攻略マニュアルの手順を、**L2（APIキーでエージェント作成まで自動）** にしたもの。
呼びかけは「えふぃぞー」、呼ばれ方は「おぬし」。

> このフォルダはオーナー個人用で、PDCA（note / BOOTH の商品づくり）の対象外です。

```
jarvis/
├── app/     … えふぃぞー本体（Macでダブルクリックして動かす）
└── reel/    … 資料を伝えるモーションリール（out/完成.mp4）
```

---

## あなたがやること（全部で約15分）

PDFの手順のうち、STEP2（エージェントを作る）とSTEP5（専用画面を作る）は自動になっています。人が必要なのは次の5つだけです。

### 1. ElevenLabs に登録する（PDFのSTEP1）
「ElevenLabs」で検索 → Sign up → Googleアカウントかメールで登録。無料プランでOK。

### 2. APIキーを作る（L2で増えた手順）
ログイン後、左のメニューの **Developers（開発者）→ API Keys** を開き、**Create API key** を押します。
- 権限を選ぶ画面が出たら、**ElevenLabs Agents：書き込み** と **Voices：読み取り** だけをオンにすれば十分です
- 出てきたキー（`sk_` で始まる長い文字）をコピーします。**このキーは他人に見せない・どこにも貼らない**
- ボタンの名前や場所は、サービスの更新で変わることがあります

### 3. このフォルダを Mac に持ってくる
GitHub でこのリポジトリを開き、ブランチを `claude/automated-work-pdca-x51uhu` に切り替えます。**Code → Download ZIP** でダウンロードして展開し、`jarvis/app` フォルダをデスクトップなどに置きます。

### 4. `start.command` をダブルクリック
初回は自動で次のことをします。
1. Node.js があるか確認する（なければダウンロードページを開いて止まる → LTSを入れてからもう一度）
2. 必要な部品を入れる（1分ほど）
3. **APIキーを聞かれるので貼る**（画面には `*` で出ます。キーは保存しません）
4. **声の一覧が出るので選ぶ**。`p 3` のように入れると試聴できます。★は日本語の確認が取れている声です
5. ElevenLabs に「えふぃぞー」を作り、日本語になっているか読み直して確かめる。Agent ID を `config.json` に保存する
6. Chrome で専用画面（http://127.0.0.1:4321）を開く

> 「開発元を確認できないため開けません」と出たら、`start.command` を**右クリック → 開く**。
> 「アクセス権がありません」と出たら、ターミナルで `chmod +x ` と打ってから `start.command` をドラッグして Enter。

### 5. 待受をオン → マイクを許可 → 「えふぃぞー」と呼ぶ
「はい、お呼びでしょうか。」と返ってきたら完成です。

**2回目からは**：`start.command` をダブルクリック → 待受をオン → 呼ぶ、だけです。

## 使い方のメモ

- **終わらせ方**：「会話を終了」ボタン／「会話を終了」「えふぃぞー終了」と言う／60秒だまる
- **反応しないとき**：画面の「聞き取った言葉」を見て、聞き間違えた形（例：「エピゾー」）を「呼びかけの言葉」に足して保存。それでもだめなら「今すぐ話す」ボタン
- **声や役割を変えたいとき**：`app/agent/system_prompt.txt`（役割の文章）や `app/agent/agent.json`（最初のひとこと）を書き換えてから、`setup.command` をダブルクリック。同じエージェントが上書き更新されます
- **もっと日本語らしい声にしたいとき**：ElevenLabs の Voice Library で日本語の声を My Voices に追加してから `setup.command` を実行すると、一覧に出ます
- **使わないときは待受をオフに**。待受中の声は Chrome の音声認識（Google）に送られます

## 中身（app/）

| ファイル | 役割 |
|---|---|
| `start.command` | 起動用（Mac）。初回は自動セットアップも行う |
| `setup.command` / `setup.mjs` | L2の自動セットアップ。APIキーでエージェントを作成・更新し、Agent IDを保存する |
| `server.mjs` | Node.js標準の http だけで動くサーバー。127.0.0.1:4321 でだけ待ち受ける |
| `public/` | 専用画面（黒い背景の中央に、状態で光り方が変わる円） |
| `agent/system_prompt.txt` | えふぃぞーの役割の文章（PDFの文章の名前と呼び方を書き換えたもの） |
| `agent/agent.json` | 名前・言語（ja）・最初のひとこと・声のモデル |
| `config.example.json` | 初期設定（呼びかけの言葉）。実際の設定は `config.json`（Git には入れない） |

専用画面は、PDFのSTEP5のプロンプトに書かれた条件（15項目）をそのまま満たすように作ってあります。接続に失敗したら websocket で1回だけやり直す、呼びかけは表記ゆれを吸収して判定する、起動チェックの○×、日本語のエラー表示と「次に確認すること」などです。

## 確認できていること／できていないこと

- ✅ サーバー：画面・部品（`lib.iife.js`、約1.1MB）・設定の読み書き。不正な Agent ID と、他のサイトからの書き換えは弾く
- ✅ 画面の流れ：偽のマイクと偽の ElevenLabs を使ってブラウザで試した。待受 → 関係ない言葉では反応しない → 「えふぃぞう」で接続 → 終了の言葉で待受に戻る → 1回目の接続に失敗したら websocket でやり直す → 終了ボタン → 待受オフ
- ✅ セットアップ：ElevenLabs に送る内容を `--dry-run` で確認した。APIの形は公式SDKの型定義で照合した
- ❌ **本物の ElevenLabs への接続と、本物の声・マイク**：この作業環境からは ElevenLabs に接続できず、マイクもないため、試せていません。最初にあなたの Mac で動かしたときが本番の確認です。エラーが出たら、黒いウィンドウの文字をそのまま Claude に貼ってください
