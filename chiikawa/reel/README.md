# モーションリール「ちいかわ」

『ちいかわ』（ナガノ）がどんな作品かを伝える、27秒のリリックモーション。
作り方は `jarvis/reel` と同じです。Canvas 1枚と Web Audio で、映像も音もすべてコードで作っています（素材ファイル・生成AI・動画用フレームワークは不使用）。

> **キャラクターの絵は描いていません。** ちいかわは作者ナガノさんの著作物です。コードで描いても、似せた絵は二次創作になります。
> そこで3人は、名前の文字と色（ちいかわ＝ピンク、ハチワレ＝青、うさぎ＝オレンジ）だけで表しました。公式ロゴや公式画像も使っていません。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | リール本体（映像と音）。画面をクリックすると音つきで頭から再生 |
| `素材_記事.md` | Web検索で調べた事実と出典。ここにない話はリールに入れていない |
| `export.mjs` | 書き出し用（puppeteer-core ＋ ffmpeg）。`--audio-only` で音だけ作り直し |
| `out/完成.mp4` | 完成品。1920×1080 / 60fps / 27.10秒 / H.264 ＋ AAC（-15.6 LUFS） |
| `out/check/*.jpg` | 目視確認に使ったコマ |

## 確認したこと

- 途中のコマを3回に分けて計27枚見て、次の点を直した
  - 場面2：飛んでいる白い粒が水色の背景に溶けて見えなかった → 飛んでいる間は青で描く
  - 場面7：声の出演の札が「朝」に重なっていた → 右へずらした
  - 場面3：途中で粒が上端に固まり、空のコマになっていた → 吸い上げる高さを下げた
- 止まって見える時間：0.5秒離れた2コマで、目に見えて変わった画素の割合を測った。最初は3か所が1%未満だったので、動きを足して直した（場面4の輪を濃い紫に、場面3の粒を揺らす、場面8の印を回す）。直したあとの最小は1.65%
- 音：-15.6 LUFS、最大 -1.1 dBFS。0.3秒以上の無音なし。**音の好みは実際に聴いて判断してください**
