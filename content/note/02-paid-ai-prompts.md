現場が終わって、事務所に戻ってからの書類仕事。
見積書の文面、施工計画書、安全書類、お客様への説明、クレームの返信……。

**現場の仕事は好きなのに、書類で夜が削られる。**

この記事は、ChatGPTやClaudeなどのAIに「そのまま貼るだけ」で使えるプロンプト（指示文）を、電気工事の実務に絞って30個まとめたものです。
【 】の部分を書き換えるだけで使えます。

## AIを使うときの3つの約束
1. **お客様の個人情報（氏名・住所・電話）は入れない**。「A様」「○○市」で十分です。
2. **数値・法令はAIの答えをうのみにしない**。計算と基準の確認は自分で（計算は無料Excelをどうぞ）。
3. **最後は自分の言葉で1行直す**。それだけで「AIっぽさ」は消えます。

## 無料で3つ公開します

### ① 見積書に添える「工事内容の説明文」
```
あなたは電気工事会社の営業担当です。以下の工事内容を、電気に詳しくない一般のお客様向けに、
見積書に添える説明文（300字程度）にしてください。専門用語には一言で補足を入れ、
安全上なぜ必要かを1文入れてください。

工事内容：【分電盤交換（主幹50A→60A、回路数12→16）、エアコン専用回路2回路増設】
お客様の状況：【築30年の戸建て、ブレーカーがよく落ちる】
```

### ② 追加工事が出たときの説明
```
工事中に追加工事が必要になりました。お客様に不快感を与えず、理由と金額と選択肢を伝える
メッセージ（LINE向け、200字以内）を作ってください。押し売りに見えないよう、
「今回見送る」選択肢と、その場合のリスクも正直に書いてください。

見つかった状況：【天井裏の既設VVFの被覆劣化、一部ステップル打ち直し不良】
追加内容と金額：【該当回路の引き替え 2回路 税込38,500円】
```

### ③ 日報をまとめる

## A. 見積・営業（7個）

### ④ 相見積もりで負けないための比較表
```
お客様が他社と相見積もりをしています。当社の見積の強みが伝わる比較表を作ってください。
価格だけで比べられないよう「使う材料のグレード」「保証」「アフター対応」「工事後の安全性」の観点を入れ、
他社を悪く言わない表現にしてください。
当社の条件：【材料はパナソニック製、施工後1年保証、24時間以内に駆けつけ】
```

### ⑤ 値引き交渉への返答
```
お客様から【10%】の値引きを求められました。利益を守りつつ関係を悪くしない返答を3パターン作ってください。
(1) 値引きせず価値で納得してもらう (2) 仕様を下げて金額を下げる (3) 小さく値引きして条件をつける
工事内容：【IH用200V回路新設】 見積金額：【税込66,000円】
```

### ⑥ 見積の「一式」を分解する
```
以下の「一式」の見積を、お客様が納得しやすいように内訳（材料・作業・諸経費）に分解する
項目案を出してください。金額は入れず、項目名と単位だけで構いません。
一式の内容：【店舗の照明LED化工事一式（天井埋込ダウンライト40台）】
```

### ⑦ ホームページ・チラシ用の紹介文
```
地域密着の電気工事店の紹介文を、チラシ用（150字）とGoogleマップのビジネス説明用（750字以内）の2種類で作ってください。
強み：【創業15年、一人親方、土日対応、エアコン工事も可】 地域：【○○市・近隣】
```

### ⑧ 口コミ依頼メッセージ
```
工事が終わったお客様に、Googleの口コミをお願いするメッセージを作ってください（LINE向け、120字）。
圧を感じさせず、書いてもらえたら嬉しい程度のトーンで。
```

### ⑨ 口コミへの返信（良い評価／悪い評価）
```
以下の口コミへの返信文を作ってください。悪い評価の場合は、言い訳せず、事実確認と改善策を短く示してください。
口コミ：【★2 作業は丁寧だったが、予定の時間より1時間遅れて連絡もなかった】
```

### ⑩ 太陽光・蓄電池・EV充電器など提案商材の説明
```
【EV用200Vコンセント設置】について、お客様がよく抱く疑問を5つ挙げ、それぞれ100字以内で答えてください。
費用の目安は書かず「現地調査のうえお見積り」としてください。
```

## C. お客様・元請け対応（6個）

### ⑲ 工事日程の調整連絡
```
お客様に工事日程の候補を伝えるメッセージを作ってください。停電時間の目安と、
当日お願いしたいこと（冷蔵庫・パソコンの準備など）を含めてください。
候補日：【10/3 午前、10/5 午後】 停電：【約2時間】
```

### ⑳ 遅刻・日程変更のお詫び
```
【前の現場が長引き】、約束の時間に【1時間】遅れることになりました。お客様への連絡文を作ってください。
言い訳を長くせず、到着予定時刻と代替案（別日も可）を示してください。
```

### ㉑ クレーム対応の初動
```
以下のクレームに対する最初の返信を作ってください。まず不安な気持ちを受け止め、
事実確認のための質問と、すぐにできる応急対応を伝えてください。責任の所在はまだ認めないでください。
クレーム：【工事してから、ときどきブレーカーが落ちるようになった】
```

### ㉒ 元請けへの工程遅延の報告
```
元請けの現場監督に、工程が遅れる見込みを報告する文を作ってください。
原因・影響範囲・挽回策・判断してほしいことを分けて、簡潔に。
状況：【前工程の天井ボード施工が遅れ、照明器具取付が2日後ろ倒し】
```

### ㉓ 請求書送付・入金催促
```
入金期日を【2週間】過ぎたお客様に送る、丁寧だが曖昧にしない催促メールを作ってください。
1回目と、さらに1週間後に送る2回目の2種類をお願いします。
```

### ㉔ 協力業者・応援の依頼

## 使いこなしのコツ
1. **役割を与える**：「あなたは電気工事会社の営業担当です」の一文で出力の質が上がります。
2. **条件は箇条書きで**：【 】の中は短く具体的に。
3. **もう一度頼む**：「もっと短く」「もっと柔らかく」「箇条書きで」と追加で頼めば直してくれます。
4. **よく使うものは保存**：スマホのメモに入れておけば、現場の休憩中でも使えます。
